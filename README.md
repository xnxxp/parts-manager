# 配件库存管理系统

## 使用方法（超级简单）

### 方法一：浏览器直接使用（推荐）

1. 找到 `www` 文件夹
2. 双击 `www/index.html` 文件，用浏览器打开即可使用
3. 数据会自动保存在浏览器中（使用 localStorage）

### 方法二：传到手机上使用

1. 把整个 `www` 文件夹传到手机
2. 用手机浏览器打开 `index.html`
3. 建议添加到手机桌面（"添加到主屏幕"）

### 方法三：打包成 APK（可选）

如需打包成真正的安卓应用，请运行 `build/一键构建.bat`

## 功能

- 配件管理（名称、型号、分类、图片）
- 多仓库管理（自定义仓库名称）
- 出入库操作（入库、出库、调拨）
- 库存预警
- 价格管理（拿货价、零售价、价格图片）
- 导出 Excel
- 数据备份/恢复
